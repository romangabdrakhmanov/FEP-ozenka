ОБНОВЛЁННАЯ ВЕРСИЯ: ОТБОР ТОЛЬКО ПО ДОЛЖНОСТЯМ

Файл отбора должен содержать один обязательный столбец: Должность.
Столбец Подразделение не нужен и не проверяется.
В анализ попадают цели по всем подразделениям, если должность присутствует в списке.

Итоговый отчёт:
Состав и оформление видимых столбцов A:O и лист «Сводка» остаются без изменений.
В колонке E «Подразделение» выводится полный путь из исходного файла,
без сокращения до двух последних уровней и без ограничения в 70 символов.
Как и для других полей анализа, пробелы по краям значения убираются при чтении.
Все столбцы первого листа входного файла (или CSV) переносятся начиная с P
в исходном порядке и скрываются средствами Excel. Чтобы увидеть их,
выделите столбцы справа от O и выберите «Показать столбцы».
Переносятся значения только тех строк, которые прошли прежний отбор.
Заголовки, дополнительные поля и типы значений XLSX сохраняются;
оформление исходного файла не копируется. Как и раньше, для ячеек с формулами
читаются сохранённые Excel результаты (data_only=True), а не сами формулы.
Если результат формулы не сохранён в источнике, значение будет пустым.

Проверка:
python -m unittest discover -s tests -v

Сборка EXE:
1. Распакуйте архив на компьютере Windows с Python 3.
2. Запустите build_exe.bat.
3. Получите dist\GoalAudit.exe.
4. На рабочий компьютер переносите только GoalAudit.exe.
